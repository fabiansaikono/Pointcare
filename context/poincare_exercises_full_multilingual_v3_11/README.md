# Poincaré exercises content pack v3.11

This pack contains 21,600 exercises.

Changes in v3.11:

- Removed the separate **Woordenschat / Vocabulary** subcategory. Vocabulary practice is covered in **Wereldkennis / World knowledge / Le Monde**.
- Regenerated **Lezen / Reading** exercises using curated, accurate emoji/object icons. The prompt does not reveal the answer; the icon is shown below the prompt.
- Regenerated **Schrijven / Writing** exercises. They now show a missing-letter pattern such as `k ? t` with metadata for a yellow question mark.
- Writing TTS uses `prompt/@ttsText` and reads the full intended Dutch word/letter sequence. It does not try to pronounce blanks or ellipses.
- Writing answer values are actual letters or Dutch vowel groups such as `a`, `aa`, `ui`, `eu`; never `correct`, `wrong1`, or words such as `een`.

Sudoku and Math Crossword remain excluded because the app generates them.
