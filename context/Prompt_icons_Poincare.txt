Create a polished SVG/vector brand asset set for an Android educational app called “Poincaré”.

The style must match a calm, premium, intelligent, space-themed learning app. It should be slightly playful but not childish. The assets should feel suitable for a smart child, not a toddler app.

Use this exact visual direction:

* dark navy space background when shown on a board;
* clean bold white linework;
* RAL 1018 bright yellow as the main accent;
* RAL 5025 cool blue as the secondary accent;
* supporting colors: white and very dark navy;
* flat vector style;
* crisp geometric forms;
* rounded corners and friendly but precise shapes;
* consistent stroke width;
* transparent-background-friendly icons;
* scalable SVG output;
* no photorealism;
* no 3D rendering;
* no cartoon mascots;
* no messy gradients;
* no tiny details;
* no excessive stars or confetti;
* no childish clipart.

Overall mood:
Smart. Focused. Calm. Curious. Space exploration. Learning in orbit.

The core brand idea is “point carré”: a point and a square.
Represent this as:

* a bright yellow circular point;
* a cool blue square;
* a white orbital curve or circular orbit;
* the point and square are in orbit together, suggesting curiosity and structure.

The logo system should include:

1. A primary wordmark: “poincaré”
2. A standalone app icon / logo mark
3. A set of seven planet-style learning icons

The visual result should be as close as possible to the provided mockup: dark navy space, white orbit lines, yellow dot, blue square, refined geometric iconography.

PRIMARY LOGO WORDMARK PROMPT

Create a refined SVG vector wordmark for the app name:

Poincaré

The wordmark should use a clean modern geometric sans-serif style, rounded but precise, premium and readable.

Key idea:
Integrate the “point carré” concept into the logo.

Make the “o” in “Poincaré” into the main symbol:

* the “o” becomes a white orbital circular curve, not a normal letter;
* inside the orbit is a bright yellow circular point;
* near the upper-left of the orbit is a small cool blue square;
* the yellow point and blue square should feel like two learning objects in orbit;
* the orbit should visually still read as the letter “o”.

The rest of the letters should be white:
P — orbit-o — i — n — c — a — r — é

The accent on the “é” must be clean and visible.

The logo should feel:

* intelligent;
* calm;
* space-themed;
* educational;
* modern;
* not childish.

Use:

* white for the wordmark;
* RAL 1018 bright yellow for the point;
* RAL 5025 cool blue for the square;
* optional very dark navy if a background is needed.

Create also a standalone logo mark:

* rounded-square app icon shape;
* dark navy background;
* white orbital circular curve;
* yellow point inside the orbit;
* blue square on the orbit near the upper-right;
* a few tiny white stars only if they remain clean at small sizes;
* one small yellow star accent is allowed;
* no text inside the app icon.

Important SVG requirements:

* clean vector paths;
* consistent stroke width;
* no raster effects;
* no complex gradients;
* transparent background version for the wordmark;
* app icon version should work inside a rounded square;
* readable at small Android launcher icon sizes.

Avoid:

* handwritten fonts;
* childish fonts;
* complex star fields;
* cartoon planets;
* over-detailed texture;
* incorrect spelling;
* missing accent on é.
