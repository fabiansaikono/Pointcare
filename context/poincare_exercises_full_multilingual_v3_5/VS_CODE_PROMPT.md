Audio requirements:

1. Some exercises use type="audio_choice" or type="audio_translation_choice".
2. These exercises contain an <audioSources> block.
3. When audioSources/@visibleText="false", do not show the audio text in the prompt.
4. Show a play button instead.
5. Use audio/@text as the TTS text.
6. Use audio/@ttsLanguage as the language for pronunciation.
7. Use audio/@audioId as the stable audio/cache identifier.
8. Never read audioId aloud.
9. Do not read answer/@value aloud unless explicitly needed. For visible answers, use localized answer displays.
10. Audio text is human-readable and should not contain underscores.

Example:

<audioSources visibleText="false" playButtonOnly="true" ttsRequired="true" kind="translation_word" sourceLocale="nl-BE" targetLocale="en-US">
  <audio locale="nl-BE" ttsLanguage="nl-BE" text="boek" audioId="translation-to-english-g1-seq0001-nl-be" />
</audioSources>
